# 📬 BulkEmail App

BulkEmail is a full-stack application that allows users to send a custom message to multiple Gmail addresses at once. It’s perfect for personal announcements, team updates, or small-scale outreach—without the complexity of enterprise tools.

## 🚀 Tech Stack

- **Frontend**: React.js (Vite)
- **Backend**: Node.js + Express
- **Email Service**: Gmail SMTP (`nodemailer`)
- **Libraries**: Axios, CORS, dotenv
- **Status**: MVP Complete ✅

---

## ✨ Features

- 🔢 Input multiple Gmail addresses
- ✍️ Write a custom message
- 📤 Send emails in bulk with one click
- 🔐 Secure email sending using environment variables
- 📊 Real-time success/failure feedback
- 🕒 Schedule emails to be sent at a later date & time.
